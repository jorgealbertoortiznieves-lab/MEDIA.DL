# MEDIA.DL

Aplicación de escritorio para descargas multimedia basada en yt-dlp y gallery-dl.

## Instalación
1. Clona este repositorio o descarga el ZIP.
2. Ejecuta 
pm install para instalar las dependencias de Electron.
3. Ejecuta 
pm start para probar la app.

## Requisitos (Motores)
Esta aplicación es una interfaz gráfica (GUI) que requiere los motores de descarga para funcionar. Debes colocar los siguientes archivos dentro de la carpeta in/ del proyecto:
- yt-dlp.exe`n- gallery-dl-app.exe`n- config1.json (Configuración de gallery-dl)

Si no los colocas en la carpeta in/, la aplicación no podrá realizar descargas.
